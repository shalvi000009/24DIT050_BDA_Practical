## 1. Problem Definition
A meteorological research organization maintains historical weather records collected from various weather stations worldwide. The organization uses Hadoop to analyze large climate datasets and study long-term temperature trends. As a Data Analytics Engineer, you are required to process the National Climatic Data Center (NCDC) weather dataset and identify the maximum, minimum, and average temperature recorded for each year using MapReduce.

## 2. Objective
- Upload NCDC weather dataset to HDFS and analyze the structure of fixed-width weather records.
- Develop and implement `mapper.py` to extract `Year`, `Air Temperature`, and `Quality Code` attributes.
- Develop and implement `reducer.py` to calculate the **Maximum Temperature** recorded per year.
- Implement supplementary Reducer scripts to calculate **Minimum Temperature** (`min_reducer.py`) and **Average Temperature** (`avg_reducer.py`).
- Execute MapReduce streaming jobs on Hadoop YARN and save results to HDFS.
- Analyze climate trends across years and identify global temperature patterns.

## 3. Dataset Description
- **Dataset:** NCDC Historical Weather Dataset (Fixed-width text format).
- **Record Parsing Offsets:**
  - `Year`: Position `line[15:19]` (4 characters, e.g., `1950`, `2020`)
  - `Air Temperature`: Position `line[87:92]` (5 characters integer representation, scaled by 10)
  - `Quality Code`: Position `line[92]` (Validation flag)
  - `Missing Indicator`: Temperature value `9999` represents missing or invalid readings.

## 4. Implementation & Technologies
- **Operating System:** Ubuntu Linux (WSL)
- **Framework:** Apache Hadoop 3.x MapReduce & YARN
- **Execution Interface:** Hadoop Streaming (`hadoop-streaming.jar` / `mapred streaming`)
- **Scripting Language:** Python 3 (`mapper.py`, `reducer.py`, `min_reducer.py`, `avg_reducer.py`)
- **Storage:** HDFS

## 5. Key Analysis & Workflow Executed
1. **HDFS Dataset Upload:** Created directory `/weather/input` in HDFS and uploaded raw NCDC weather files.
2. **Mapper Logic (`mapper.py`):** Read lines from `sys.stdin`, extracted fixed-position substrings for Year (`line[15:19]`) and Air Temperature (`line[87:92]`), filtered out missing records (`9999`), and printed tab-separated key-value pairs (`year\ttemperature`).
3. **Max Reducer Logic (`reducer.py`):** Processed sorted `(year, temperature)` records, maintained `current_year` and `maximum_temperature` trackers, updated maximum values, and outputted `year\tmax_temp`.
4. **Min & Avg Reducer Execution (`min_reducer.py`, `avg_reducer.py`):** Executed supplementary MapReduce tasks to compute minimum yearly temperatures and average annual climate metrics (`average = total_temp / count`).
5. **Output Verification:** Examined HDFS output files in `/weather/output_max/part-00000` to verify trend calculations.

## 6. Key Questions & Analysis (Viva Answers)

**Q1. How is weather data parsed and processed using MapReduce?**  
Weather records in fixed-width text format are read line-by-line by the Mapper. The Mapper extracts `Year` (`line[15:19]`) and `Air Temperature` (`line[87:92]`), filters invalid readings (`9999`), and emits `(year, temp)` key-value pairs. Hadoop's Shuffle & Sort groups all temperatures for the same year and passes them to the Reducer, which calculates the maximum, minimum, or average temperature for each year.

**Q2. What key-value pairs are generated by the Mapper?**  
The Mapper generates the `Year` as the Key and the `Air Temperature` as the Value.  
- **Format:** `(year, temperature)`  
- **Example Output:**  
  ```
  2020    35
  2020    38
  2021    36
  2021    40
  ```

**Q3. How does the Reducer identify the maximum temperature for a given year?**  
The Reducer receives grouped temperature values belonging to the same year (e.g., `2020 -> [35, 38, 36, 40]`). It iterates through the temperature list, compares each value with a running `maximum_temperature` variable, updates the max value when a higher reading is found, and emits `2020\t40`.

**Q4. What challenges arise when processing large climate datasets?**  
- Handling massive dataset volume across global weather stations.
- Parsing fixed-width legacy record formats efficiently.
- Filtering corrupted, invalid, or missing sensor values (`9999` indicators).
- Dealing with data skewness across different geographical locations and years.

## 7. How to Run / Commands Executed

```bash
# 1. Upload Weather Data to HDFS
hdfs dfs -mkdir -p /weather/input
hdfs dfs -put ncdc_weather.txt /weather/input/

# 2. Run MapReduce Job for Maximum Temperature
mapred streaming \
  -files mapper.py,reducer.py \
  -mapper mapper.py \
  -reducer reducer.py \
  -input /weather/input/ncdc_weather.txt \
  -output /weather/output_max

# 3. View Maximum Temperature Results
hdfs dfs -cat /weather/output_max/part-00000

# 4. Run MapReduce Job for Minimum Temperature
mapred streaming \
  -files mapper.py,min_reducer.py \
  -mapper mapper.py \
  -reducer min_reducer.py \
  -input /weather/input/ncdc_weather.txt \
  -output /weather/output_min

# 5. Run MapReduce Job for Average Temperature
mapred streaming \
  -files mapper.py,avg_reducer.py \
  -mapper mapper.py \
  -reducer avg_reducer.py \
  -input /weather/input/ncdc_weather.txt \
  -output /weather/output_avg
```
