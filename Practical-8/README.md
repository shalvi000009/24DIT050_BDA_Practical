## 5. Spark Window Functions & Analytical Methodology

### A. Window Specification Setup
Unlike standard `groupBy()`, which collapses rows into a single summary row per group, **Spark Window functions** compute cumulative or relative metrics across rows while retaining individual row-level detail.

```python
from pyspark.sql.window import Window
from pyspark.sql.functions import lag, col, avg, first, last, stddev

# Window partitioned by stock symbol and ordered by timestamp
window_spec = Window.partitionBy("Stock").orderBy("Timestamp")
```

---

### B. Mathematical Formulas

#### 1. Daily Return Formula
Calculates day-over-day price change percentage using the `lag()` window function:
$$\text{Daily Return (\%)} = \left( \frac{\text{Current Price} - \text{Previous Price}}{\text{Previous Price}} \right) \times 100$$
*PySpark Implementation:*
```python
df_with_returns = df.withColumn("PreviousPrice", lag("Price", 1).over(window_spec)) \
    .withColumn("DailyReturn", 
        when(col("PreviousPrice").isNull(), 0.0)
        .otherwise(((col("Price") - col("PreviousPrice")) / col("PreviousPrice")) * 100)
    )
```

#### 2. 3-Period Moving Average Formula
Calculates the average price across the current row and the prior 2 rows using a sliding window:
$$\text{Moving Average}_{3P} = \frac{\text{Price}_{t} + \text{Price}_{t-1} + \text{Price}_{t-2}}{3}$$
*PySpark Implementation:*
```python
ma3_window = Window.partitionBy("Stock").orderBy("Timestamp").rowsBetween(-2, 0)
df_with_ma = df_with_returns.withColumn("MovingAverage3P", avg("Price").over(ma3_window))
```

#### 3. Volatility Formula (Standard Deviation of Daily Returns)
Measures variation in daily returns:
$$\text{Volatility} = \sqrt{\frac{\sum (R_t - \bar{R})^2}{N - 1}}$$
*PySpark Implementation:*
```python
df_volatility = df_with_returns.groupBy("Stock").agg(stddev("DailyReturn").alias("Volatility"))
```

#### 4. Cumulative Return (Top-Performing Stock Metric)
Determines the net percentage return from the initial day to the last trading day:
$$\text{Cumulative Return (\%)} = \left( \frac{\text{Last Price} - \text{First Price}}{\text{First Price}} \right) \times 100$$
*PySpark Implementation:*
```python
unbounded_window = Window.partitionBy("Stock").orderBy("Timestamp") \
    .rowsBetween(Window.unboundedPreceding, Window.unboundedFollowing)

df_analysis = df.withColumn("FirstPrice", first("Price").over(unbounded_window)) \
                .withColumn("LastPrice", last("Price").over(unbounded_window))
```

## 7. Viva Voce Questions & Answers (25 Comprehensive Questions)

### Q1: What is Apache Spark?
**Answer:** Apache Spark is an open-source, unified distributed engine designed for big data processing and large-scale analytics, featuring in-memory computing for fast execution.

### Q2: What is a Spark DataFrame?
**Answer:** A Spark DataFrame is a distributed collection of data organized into named columns, conceptually equivalent to a table in a relational database or pandas DataFrame, but optimized under Spark SQL.

### Q3: What is a Window function in PySpark?
**Answer:** A Window function performs calculations across a set of table rows that are related to the current row, without collapsing the individual rows into a single aggregated output.

### Q4: Why do we use `partitionBy()` in a Spark Window specification?
**Answer:** `partitionBy()` defines how data is divided into logical groups (partitions) across nodes. For stock analytics, `partitionBy("Stock")` ensures calculations like moving average or lag are computed independently per stock symbol.

### Q5: What does `orderBy()` do in a Window specification?
**Answer:** `orderBy()` establishes the logical sequence of rows within each partition. Ordering by `Timestamp` ensures sequential calculations (such as daily returns and moving averages) process in chronological order.

### Q6: What is the `lag()` function in PySpark?
**Answer:** `lag(col, offset)` is a window function that accesses data from a previous row at a specified offset within the partition, without needing a self-join.

### Q7: What is the `lead()` function in PySpark?
**Answer:** `lead(col, offset)` is a window function that accesses data from a subsequent (future) row at a specified offset within the partition.

### Q8: Why is `lag()` useful for stock market analysis?
**Answer:** `lag()` allows us to retrieve the previous trading day's closing price for a stock to calculate day-over-day price change and daily returns percentage.

### Q9: What happens to the first row of each partition when using `lag()`?
**Answer:** Since the first row has no preceding row in the partition, `lag()` returns `NULL`. We handle this using `when(col("PreviousPrice").isNull(), 0.0)` to assign a default zero return.

### Q10: What is a moving average?
**Answer:** A moving average is a technical indicator that smooths out short-term price fluctuations by averaging prices over a specific rolling window of periods.

### Q11: How is a 3-period moving average computed using Spark Window?
**Answer:** By applying `avg("Price").over(window)` where the window specification includes `rowsBetween(-2, 0)`, which includes the current row and the prior 2 rows.

### Q12: What does `rowsBetween(-2, 0)` mean?
**Answer:** `rowsBetween(-2, 0)` defines a relative row frame starting 2 rows before the current row (`-2`) and ending at the current row (`0`).

### Q13: What is daily return and how is it calculated?
**Answer:** Daily return measures the percentage price change between two consecutive days:
$$\text{Return} = \frac{\text{Current Price} - \text{Previous Price}}{\text{Previous Price}} \times 100$$

### Q14: What is stock volatility?
**Answer:** Volatility refers to the degree of variation in stock prices over time. In quantitative analytics, it is measured by calculating the standard deviation of daily percentage returns.

### Q15: How does standard deviation represent stock volatility?
**Answer:** A higher standard deviation indicates greater dispersion of daily returns around the mean, representing higher price fluctuation risk.

### Q16: What is the main difference between `groupBy()` and PySpark Window functions?
**Answer:** `groupBy()` aggregates multiple rows into a single summary row per group, losing individual row detail. Window functions compute aggregations over defined frames while retaining all input rows.

### Q17: What is Cumulative Return?
**Answer:** Cumulative Return measures the aggregate percentage change in stock price from the start of an analytical period to the end of that period:
$$\text{Cumulative Return} = \frac{\text{Last Price} - \text{First Price}}{\text{First Price}} \times 100$$

### Q18: Why is highest stock price not necessarily the best performing stock?
**Answer:** Stock price is dependent on total share supply and split history. Performance is evaluated on percentage capital appreciation (returns), not absolute dollar price per share.

### Q19: How do `first()` and `last()` window functions work with unbounded frames?
**Answer:** Using `rowsBetween(Window.unboundedPreceding, Window.unboundedFollowing)` ensures `first()` returns the earliest value and `last()` returns the latest value across the entire partition regardless of row position.

### Q20: What is lazy evaluation in Spark?
**Answer:** Lazy evaluation means Spark builds an execution lineage plan (DAG) for transformations, executing actual computations only when an action (e.g., `.show()`, `.count()`, `.collect()`) is triggered.

### Q21: What is the difference between a Transformation and an Action in Spark?
**Answer:** Transformations (e.g., `filter`, `withColumn`, `groupBy`) return a new DataFrame lazily. Actions (e.g., `show`, `count`, `collect`, `write`) trigger computation and return results to the driver program or write output.

### Q22: Why should we avoid calling `.collect()` on large DataFrames to the driver node?
**Answer:** `.collect()` fetches the entire distributed dataset into the driver's memory. On large datasets, this causes Out-Of-Memory (OOM) driver crashes.

### Q23: Why is Spark suitable for financial stock data analytics?
**Answer:** Financial market data involves high-velocity, high-volume time-series streams. Spark's in-memory distributed architecture enables scalable window-based stream and batch analytics.

### Q24: What is `spark.sql.shuffle.partitions`?
**Answer:** It configures the number of partitions created when shuffling data across nodes during aggregations or window partitioning. In local mode, setting it to a small number (e.g., 4) optimizes performance.
