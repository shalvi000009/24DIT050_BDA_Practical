Scalable K-Means Clustering on Customer Segmentation Data using Apache Spark MLlib
================================================================================

1. OBJECTIVE & PROBLEM DEFINITION
--------------------------------------------------------------------------------
RetailEdge Analytics marketing team requires segmenting >10M customer profiles based on
historical purchase behavior. Traditional single-node clustering algorithms face out-of-memory
(OOM) errors and processing bottlenecks. This practical demonstrates scalable parallel K-Means
using Apache Spark MLlib.

2. DATASET SUMMARY & PREPROCESSING
--------------------------------------------------------------------------------
Dataset Size: 20,000 Records (Demonstration Dataset)
Features Extracted: total_spend, purchase_count, avg_basket_size, days_since_last_purchase
Excluded Fields: customer_id (Excluded to prevent numerical identifier bias)
Scaling Method: Spark MLlib StandardScaler (withMean=True, withStd=True)

3. SPARK MLLIB K-MEANS EXPERIMENTAL RESULTS (k=5)
--------------------------------------------------------------------------------
Training Time: 3.5010 seconds
Within Set Sum of Squared Errors (WSSSE): 10,837.73

6. CONCLUSION & ARCHITECTURAL TAKEAWAYS
--------------------------------------------------------------------------------
1. Spark MLlib StandardScaler ensures fair Euclidean distance weighting across features.
2. The Elbow Method (k=3..7) validated k=5 as the optimal trade-off between compactness and complexity.
3. Distributed parallel K-Means provides horizontal scalability across large-scale HDFS datasets.
4. On small local datasets, single-node scikit-learn has lower JVM initialization overhead, but
   Spark MLlib is indispensable for multi-gigabyte or multi-terabyte datasets.
